# Assignment-05
🛒 Grocery Product Catalog — CRT Assignment 5
An interactive and clean grocery product listing web app built using HTML, CSS, and JavaScript, powered by mock data (no backend required). Designed to be responsive and intuitive, the application presents a catalog of grocery items with detailed views and QR code sharing.

🔗 Live Preview
👉 Open Live Demo(https://shoppingappass-05.netlify.app/)

✨ Key Highlights
✅ Mock API Integration: No real backend needed—runs on local/fake data

✅ Responsive Grid Layout: Displays various grocery products in a clean, responsive interface

✅ Interactive Product Cards: Click on any item to explore detailed information

✅ QR Code Generator: Instantly generate a QR code for each product for quick access or sharing

✅ Smooth UX: Minimalist design, hover animations, and a mobile-friendly experience

🛠️ Tech Stack
Frontend: HTML5, CSS3, Vanilla JavaScript

QR Code: QRCode.js for generating QR codes
